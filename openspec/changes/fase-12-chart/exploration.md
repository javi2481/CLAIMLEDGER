Architecture is CLOSED. Rector §20 and §21 name this phase: a chart of an already verified series. Open WebUI draws. CLAIMLEDGER does not let a model invent a bar.

## Gate

`docs/plan-implementacion.md` wave C: “¿Ya hay serie verificada?” Yes. `query` on a compare Intent returns two `recorded` claims (`21262335`, `81956525`) and no delta. That pair is the series. A single claim is still a card. An abstention is still no answer. The user asked to open phase 12 on 2026-10-07.

The book has two periods, not four. A missing period is a hole in the spec. Nothing in this change writes a third or fourth gold number.

## What already draws

Open WebUI renders a Mermaid fence. It does not know which digits the kernel verified. Matplotlib and Artifact are later rungs of the same ladder (axes across years; click → card). This series is two bars. Mermaid is the rung that matches. Running Code Interpreter to “calculate the balance” stays forbidden.

## Gap

No pinned API turns a `QueryResult` into `{title, points[], status}` whose bar heights are claim values. Custom code is that spec, plus a Mermaid fence copied from it. The fence is what Open WebUI already draws.
